The Internship Journey

8 tasks. 30 days. One complete platform.

TechBridge runs a 30-day, fully practical internship. Instead of lectures, you complete eight hands-on tasks, each one building on the last, so your web development skills grow progressively — from your first static page to a complete, connected platform you can put in your portfolio.

Internship progression

Day 1 → Day 4 → Day 8 → Day 11 → Day 15 → Day 19 → Day 22 → Day 26

Eight tasks, spread across 30 days, each one building on the last.

The 8 internship tasks

Each task unlocks a few days after the last, and the difficulty steps up as you go. Tap any task to see what it involves.

  1. 1
    Day 1 Beginner

    Build the TechBridge Homepage

    Create the first version of the TechBridge website using HTML and CSS.

    HTML5 CSS3
    What this task involves
    • Structure a homepage with semantic HTML5
    • Style it from scratch with plain CSS3, no frameworks
    • Introduce TechBridge and its two program tracks
    • Ship it as the foundation every later task builds on
  2. 2
    Day 4 Beginner

    Build the TechBridge Programs Experience

    Create a Programs experience that presents TechBridge's available learning programs.

    HTML5 CSS3
    What this task involves
    • Detail the Data Analytics and Web Development tracks
    • Add a filterable, card-based layout for each program
    • Compare both tracks side by side
    • Connect it back to the homepage with shared navigation
  3. 3
    Day 8 Beginner → Intermediate

    Build the Internship Tasks Experience

    Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

    HTML5 CSS3
    What this task involves
    • Explain the 30-day internship at a glance
    • Represent all 8 tasks with day, title, and description
    • Make the day-by-day progression easy to follow
    • Communicate the beginner-to-advanced difficulty curve
    • Work fully without JavaScript, on any screen size
  4. 4
    Day 11 Intermediate

    Build an Interactive Task Tracker

    Use JavaScript to make the internship task experience interactive and allow progress to be tracked.

    HTML5 CSS3 JavaScript
    What this task involves
    • Add interactivity on top of the Task 3 layout
    • Let a visitor mark tasks as complete
    • Persist and reflect progress in the interface
    • First task in the internship that requires JavaScript
  5. 5
    Day 15 Intermediate

    Build the Intern Registration Experience

    Create a professional registration and onboarding interface for TechBridge interns.

    HTML5 CSS3
    What this task involves
    • Design a clean, guided sign-up flow
    • Validate and structure form fields with semantic HTML
    • Give new interns a welcoming first impression
  6. 6
    Day 19 Intermediate → Advanced

    Build the Task Submission System

    Create an interface through which interns can prepare and submit their task work.

    HTML5 CSS3 JavaScript
    What this task involves
    • Design an upload or link-submission workflow
    • Confirm and display submission status
    • Handle the flow for all 8 tasks, not just one
  7. 7
    Day 22 Advanced

    Build the Intern Dashboard

    Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

    HTML5 CSS3 JavaScript
    What this task involves
    • Bring profile, progress, tasks, and submissions together
    • Design an at-a-glance overview of the whole internship
    • Reuse and extend components built in earlier tasks
  8. 8
    Day 26 Advanced

    Build the Complete TechBridge Internship Platform

    Combine the different components created during the internship into a complete TechBridge platform.

    HTML5 CSS3 JavaScript
    What this task involves
    • Merge Tasks 1–7 into one cohesive platform
    • Polish navigation, consistency, and responsiveness
    • Ship the finished internship capstone project
